# ATLAS Market Intelligence

A dark, mobile-first Indonesian stock market analysis terminal. The current build is a DEMO prototype; it does not use live market feeds or provide investment guarantees.

## Android APK
Push to `main` triggers GitHub Actions to build a debug APK. Open **Actions → Android APK Build → latest run → Artifacts** to download `atlas-debug-apk`.

## Features
- Market overview dashboard
- Demo stock watchlist and scanner
- Stock detail cards with indicative technical metrics
- AI analyst-style scenarios (demo copy, not connected to AI)
- Local watchlist and paper trading UI

## Disclaimer
Demo values are illustrative and are not live IDX data or investment advice.
